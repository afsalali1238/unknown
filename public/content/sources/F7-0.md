Unix is a family of multitasking, multi-user computer operating systems derived from the original AT&T Unix, whose development began in 1969 at Bell Labs by Ken Thompson, Dennis Ritchie, Douglas McIlroy, Joe Ossanna, and others. The first internal manual appeared in November 1971; the system was announced outside Bell Labs in 1973, and Ritchie and Thompson's paper "The UNIX Time-Sharing System" appeared in the *Bell System Technical Journal* in 1978.

Unix was born partly from the failure of Multics, an ambitious and enormous time-sharing system Bell Labs had participated in and then withdrawn from. Thompson began experimenting with a small, simple operating system on a spare PDP-7; Ritchie joined, and the team deliberately did the opposite of the Multics approach: rather than design one grand system meeting every requirement, they built a minimal kernel and a small set of tools. The decisive engineering move came in 1973 when the operating system was rewritten in the newly created C programming language, making Unix the first widely used portable operating system — instead of being welded to one machine in assembly language, it could be carried to new hardware with modest effort.

The design principles that made Unix influential became known as the **Unix philosophy**. The operating system should provide simple tools, each doing one limited thing well; tools should work together through plain text interfaces, especially pipes — McIlroy's invention, which lets the output of one program become the input of another; and tools should be combinable, so users (not just system designers) can build new behavior from the pieces. Rather than supplying one monolithic program per task, Unix supplied a toolbox: list files, filter text, sort, count, and let the user connect these in novel ways. Text streams became the universal interface, a decision that echoes the end-to-end and narrow-waist design later used in TCP/IP.

AT&T's licensing of Unix to universities in the late 1970s spread it widely and cheaply; the University of California, Berkeley produced the Berkeley Software Distribution (BSD), adding TCP/IP, virtual memory, and the vi editor, while commercial variants (SunOS/Solaris, HP-UX, AIX) powered the workstation and minicomputer era. A young Finnish student's 1991 reimplementation of the Unix interface as the Linux kernel — together with the GNU toolset — made Unix design the basis of essentially all modern computing: Linux runs servers, Android phones, and the cloud; macOS and iOS are certified Unix descendants (via BSD); and the command line, the process model, and the file-as-everything abstraction remain the working vocabulary of software.

Douglas McIlroy summarized the philosophy: write programs that do one thing and do it well; write programs to work together; write programs to handle text streams, because that is a universal interface. Unix proved that restraint — minimalism, composition, portability — could outlast and outperform comprehensive design, an influence that extends to today's microservices, command-line tools, and the culture of small composable software.
