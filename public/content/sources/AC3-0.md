Turing machines, first described by Alan Turing in 1936–37, are simple abstract computational devices intended to investigate the extent and limits of what can be computed. Turing called them "automatic machines"; they were named "Turing machines" by Alonzo Church in a 1937 review. They remain the foundational model of computability and theoretical computer science.

A Turing machine is deliberately primitive. It consists of a tape, divided into squares, each square holding one symbol (or blank); a head that reads and writes one square at a time and moves left or right; and a finite list of states with transition rules. At any moment the machine's behavior is completely determined by its current state and the symbol it is scanning. A rule says: in this state, seeing this symbol, print this new symbol, move one square left or right (or stay), and enter this next state. That is all.

Turing introduced the machine to settle the *Entscheidungsproblem* — David Hilbert's challenge to find a general effective procedure deciding, for every statement of first-order logic, whether it is derivable. To ask whether such a procedure exists, Turing first needed a precise definition of "effective procedure," and the machine provided it: anything a human clerk can compute by rote, following rules with no insight, can be computed by such a machine. This identification — the **Church–Turing thesis** — says the informal idea of "algorithmically computable" exactly matches "computable by a Turing machine."

The machine's greatest conceptual descendant is the **universal Turing machine**. A machine's behavior is given by its finite table of rules; that table can itself be written as symbols on a tape. Turing showed that a single machine can read any other machine's description from its tape and then simulate it. This is the stored-program computer in abstract form: one device can run any computation, given a description of it — program and data made of the same stuff.

Turing then proved the limits. The **halting problem** — construct a machine that decides, given the description of any machine and its input, whether that machine will ever halt — has no solution. A hypothetical halting decider can be turned against itself in a diagonal contradiction: feed it a program that does the opposite of whatever it predicts, and it refutes itself. This gave the negative answer to the Entscheidungsproblem: there is no general decision procedure for logic, and therefore well-posed mathematical questions exist that no algorithm can answer. Kurt Gödel's incompleteness theorems had shown related limits within formal arithmetic; Turing showed the limit was intrinsic to mechanical computation itself.

Every real computer, from the 1940s onward, is computationally equivalent to a Turing machine (allowing for finite memory): if a problem cannot be solved by a Turing machine in principle, no amount of hardware ingenuity can solve it. The model's lesson is that computation has hard, provable boundaries — and that the idea of the general-purpose machine, the universal simulator, was understood in theory a decade before it was built in hardware.
